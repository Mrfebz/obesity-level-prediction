# obesity-level-prediction
Predicts obesity level categories (underweight to obese) using classification models trained on demographic, dietary, and lifestyle features.
# Obesity Level Classification Using Machine Learning

## Project Overview

This project uses machine learning to classify individuals into different obesity-level categories based on eating habits, physical condition, and demographic information.

A multiclass Logistic Regression model using the One-vs-One classification strategy is implemented.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Logistic Regression
* One-vs-One Classification
* One-Hot Encoding
* StandardScaler

## Machine Learning Workflow

1. Load the dataset
2. Explore the dataset
3. Check missing values
4. Remove duplicate records
5. Separate features and target
6. Identify categorical and numerical features
7. Apply One-Hot Encoding
8. Apply feature scaling
9. Split data into training and testing sets
10. Train a Logistic Regression model using One-vs-One classification
11. Generate predictions
12. Evaluate the model using accuracy and classification metrics
13. Visualize the confusion matrix
14. Make predictions for new input data

## Target Variable

The target variable is `NObeyesdad`, which represents different obesity levels.

## Dataset

The project uses the Obesity Level Prediction dataset.

## Results

The model's performance is evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## Project Purpose

This project demonstrates practical skills in Python programming, data preprocessing, exploratory data analysis, feature engineering, machine learning classification, and model evaluation.
